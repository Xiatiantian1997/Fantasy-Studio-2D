# 2D 绘画模块｜实现计划

> 总体产品与统一 UI 已交给 [Fantasy Studio 总控](https://github.com/Xiatiantian1997/Fantasy-Studio-) 管理。本文件仅记录 2D 生成能力，不再当成整套软件的总体产品规范。

## 目标

用 ComfyUI 作为生成引擎，稳定实现**幻真动漫、半写实插画、数字油画**三种真正不同的 2D 视觉语言，并可接收参考图片、姿势、材质与 3D 结构控制图。

保留现有实现，不把原先能出图的开发工作流再造一遍。

## 阶段与验收

1. **GPU 实机出图**：在目标 Windows RTX 3060 Ti 8GB 机器上验证文生图、整图 img2img、模型切换、LoRA、停止与保存；保留日志。
2. **三种画风配方**：分别选用实际匹配的模型和/或 LoRA。保存模型、采样器、正负提示词、种子、参数；用同一成年原创角色和姿势测试明显的画风差异，不能只是一个滤镜。
3. **素材引用**：通过总控给出的稳定素材 ID 读取允许访问的参考，支持人物、服装、光影或特征参考；不独立建第二套全局数据库。
4. **动作控制**：先支持姿势线稿/骨架，之后接收 3D 结构包中的 Depth/Normal/Pose。ControlNet 与基础 checkpoint 必须兼容。
5. **局部编辑**：图像蒙版、边界保护、前后版本比较；保持原图可追溯。
6. **任务返回**：对总控提供生成图片、任务状态、种子和风格配方 ID，不要求用户直接接触 ComfyUI 节点图。

## 与 3D 的界限

**2D 不制作人体网格和形变修正**，只消费由 3D 模块输出并验证的控制包。3D 格式以 [导出规范](https://github.com/Xiatiantian1997/Fantasy-Studio-3D/blob/main/docs/interface-v0.1.md) 为唯一权威。

## 与总控的界限

总控负责软件导航、素材/角色与作品索引、AI/用户权限、统一启动和跨模块状态。2D 当前自己的 HTML 页面只是开发测试前端；总控稳定后才转移对外运行入口，不能无验证删除旧脚本。

## 当前状态

已有 2D 基础生成代码和开发界面；**尚未完成目标 GPU 实机验收，也没有真正的三画风稳定配方和 ControlNet 支持**。这里没有其他软件版本的概念。
